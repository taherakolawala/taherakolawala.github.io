# Taher Akolawala Portfolio

Static portfolio site deployed with GitHub Pages.

## Structure

- `index.html` — GitHub Pages entry point, page markup, and interactive component logic.
- `assets/css/site.css` — site-wide styles, themes, and diagram motion.
- `assets/js/portfolio-data.js` — experience, leadership, project, and visual-flow content.
- `support.js` — Design Component runtime required by the site.
- `taher-akolawala-resume.pdf` — downloadable resume.

## Editing content

Add or update portfolio entries in `assets/js/portfolio-data.js`. Adjust the page structure and behavior in `index.html`, and visual styling in `assets/css/site.css`.

Open `index.html` locally, or use the GitHub Pages URL after deployment.
